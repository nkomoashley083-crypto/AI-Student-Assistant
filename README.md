# AI Student Assistant 🎓

AI Student Assistant is an AI-powered platform that helps students manage their studies, improve productivity, write professional emails, conduct research, and prepare for internships and careers.

**Live app:** [student-mentor-ai-23.lovable.app](https://student-mentor-ai-23.lovable.app/)
**Repository:** [github.com/nkomoashley083-crypto/AI-Student-Assistant](https://github.com/nkomoashley083-crypto/AI-Student-Assistant)

---

## ✨ Features

- **Study & Productivity Support** – Helps students organize tasks, manage time, and stay on top of their academic workload.
- **Professional Email Writing** – Generates polished, professional emails for academic and career-related communication.
- **Research Assistance** – Supports students in conducting and structuring research more efficiently.
- **Career & Internship Prep** – Provides guidance and tools to help students prepare for internships and career opportunities.
- **Conversational AI Interface** – A chat-style assistant built on an AI SDK for natural, real-time interaction.

## 🛠️ Tech Stack

This project was built using **[Lovable](https://lovable.dev)**, an AI-assisted app builder, on top of the following stack:

| Layer | Technology |
|---|---|
| Framework | [TanStack Start](https://tanstack.com/start) + [React 19](https://react.dev/) |
| Routing / Data | [TanStack Router](https://tanstack.com/router) & [TanStack Query](https://tanstack.com/query) |
| Build Tool | [Vite](https://vitejs.dev/) |
| Styling | [Tailwind CSS 4](https://tailwindcss.com/) + [Radix UI](https://www.radix-ui.com/) primitives |
| AI Integration | [Vercel AI SDK](https://sdk.vercel.ai/) (`ai`, `@ai-sdk/react`, `@ai-sdk/openai-compatible`) |
| Backend / Database | [Supabase](https://supabase.com/) |
| Forms & Validation | React Hook Form + Zod |
| Language | TypeScript |

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or later recommended)
- [Bun](https://bun.sh/) (the project uses `bun.lock`) or npm/yarn as an alternative
- A [Supabase](https://supabase.com/) project (for backend/database features)

### Installation

1. Clone the repository:
```bash
   git clone https://github.com/nkomoashley083-crypto/AI-Student-Assistant.git
   cd AI-Student-Assistant
```

2. Install dependencies:
```bash
   bun install
   # or
   npm install
```

3. Configure environment variables:
   Create a `.env` file in the project root with your Supabase and AI provider credentials.

4. Run the development server:
```bash
   bun run dev
   # or
   npm run dev
```

5. Open the app in your browser at the local URL shown in your terminal (typically `http://localhost:5173`).

### Available Scripts

| Command | Description |
|---|---|
| `dev` | Starts the local development server |
| `build` | Builds the app for production |
| `build:dev` | Builds the app in development mode |
| `preview` | Previews the production build locally |
| `lint` | Runs ESLint checks |
| `format` | Formats code with Prettier |
